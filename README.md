# Блокнот

Блокнот для строки меню macOS с оранжевым значком Kraken. Вкладка «Доступы» хранит рабочие учётные записи, а дополнительные листы предназначены для заметок.

## Установка

Откройте `Блокнот.dmg`, перетащите приложение в «Программы» и запустите его оттуда. Значок появится в строке меню. Приложение регистрирует себя в «Объектах входа» при запуске с локального диска.

Готовый образ собран для Apple Silicon. Минимальная версия системы — macOS 13.

## Сборка

На Mac с Xcode Command Line Tools выполните `bash build.sh`. Скрипт создаст `Блокнот.dmg` для архитектуры текущего Mac. Приложение в образе имеет локальную подпись.

Пароли хранятся в одной общей записи локальной Связки ключей macOS. Старые отдельные записи переносятся при первом чтении. macOS может запросить разрешение при переносе или после смены подписи приложения. Карточки и заметки сохраняются в настройках приложения. Синхронизации между Mac в текущей версии нет.


## Возможности версии 1.27

- Три карточки в поле зрения. На macOS 15 и новее прокрутка трекпадом сдвигает ряд по одной карточке.
- Многострочное описание сервера под паролем. Пароль оформлен как строка логина.
- Копирование адреса, логина и пароля отдельными кнопками. Глазик и карандаш для пароля находятся внизу карточки.
- Добавление доступа через плюс в правой части вкладки «Доступы». Удаление карточек и листов требует подтверждения.
- Произвольные названия листов, сохранение текста и палитра из четырёх цветов. Цвет для доступов общий, цвет заметок задаётся отдельно на каждом листе.
- Типы карточек в порядке VPS, 3x-UI, GitHub, Сервер, Админка, Другое.
- Оранжевый Kraken в Finder и строке меню. Автозапуск при входе в macOS после первого запуска установленного приложения.

Версия 1.23 использует идентификатор Kraken. При первом запуске она подхватывает прежние заметки и карточки. Пароли переносятся при обращении к Связке ключей, которая может запросить разрешение.
