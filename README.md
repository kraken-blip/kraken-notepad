# Блокнот Kraken 1.29

Блокнот в строке меню macOS для заметок и рабочих доступов.

## Установка

Откройте Блокнот.dmg, перенесите приложение в «Программы» и запустите его оттуда. Готовый DMG собран для Apple Silicon, macOS 13 или новее. Сборка имеет локальную подпись.

При первом запуске приложение регистрирует объект входа macOS. Если автозапуск выключен, проверьте раздел «Объекты входа» в системных настройках. Блокнот запускается после входа в учётную запись.

## Что умеет версия 1.29

- Через плюс рядом с вкладками можно создать текстовый лист или именованный лист доступов.
- Карточки поддерживают название, необязательный логин и ссылку, пароль и многострочное описание. Изменение описания открывается через карандаш в квадрате.
- На macOS 15 и новее горизонтальная прокрутка сдвигает ряд на одну карточку. Три карточки помещаются на экране одновременно.
- Кнопка справа от текста копирует содержимое всего листа. Выбор значка, сохранение и отмена закреплены внизу формы карточки.
- При удалении листа доступов его карточки перемещаются в основные «Доступы».

Карточки и листы хранятся локально. Пароли сохраняются в Связке ключей macOS. Данные пользователя не входят в DMG.

## Сборка

На Mac с Xcode Command Line Tools выполните `bash build.sh`. Образ появится в корне проекта.
