# Блокнот

Блокнот для строки меню macOS с оранжевым значком Kraken. Вкладка «Доступы» хранит рабочие учётные записи, а дополнительные листы предназначены для заметок.

## Установка

Откройте `Блокнот.dmg`, перетащите приложение в «Программы» и запустите его оттуда. Значок появится в строке меню. Приложение регистрирует себя в «Объектах входа» при запуске с локального диска.

Готовый образ собран для Apple Silicon. Минимальная версия системы — macOS 13.

## Сборка

На Mac с Xcode Command Line Tools выполните `bash build.sh`. Скрипт создаст `Блокнот.dmg` для архитектуры текущего Mac. Приложение в образе имеет локальную подпись.

Пароли хранятся в локальной Связке ключей macOS. Карточки и заметки сохраняются в настройках приложения. Синхронизации между Mac в текущей версии нет.
